# ADR-0002：绘本解析使用本地 Agent CLI

- **Status:** Accepted
- **Date:** 2026-08-26（由现有实现补录）

## 背景

绘本导入需要多模态模型从图片提取正文、翻译、词汇和问题。运行环境已有登录完成的 `agy` 与 `codex` CLI，并希望避免在应用中保存独立 API Key。

## 决定

FastAPI AI service 根据配置选择 `agy` 或 `codex` 及允许的模型，通过本地进程调用完成解析。CLI 凭据由运行环境提供；应用只处理图片、提示词、结构化输出和错误映射。

## 后果

- 应用不直接持有模型 API Key，但仍必须保护 CLI 的登录目录和调用额度。
- 容器需要访问 CLI 可执行文件和最小必要凭据，部署可移植性下降。
- CLI 版本、模型名称和输出格式可能变化，必须通过配置、超时、Schema 校验和测试隔离。
- 模型输出只能作为草稿，不能未经管理员确认自动发布。
- 新增其他 Agent 工具需显式配置适配器，不能把任意请求值当作可执行命令。

## 未选择方案

- 在源码或 `.env` 中维护模型 API Key：增加密钥管理面和泄漏风险。
- 让 Backend 直接执行任意 shell：扩大业务服务权限，并引入命令注入风险。
- 让 AI service 直接写数据库：绕过管理员确认和 Backend 业务事务。
