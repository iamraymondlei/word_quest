# 内容管理与 AI 绘本导入

## 1. 范围

管理员界面维护学员、故事、词汇、分组、故事访问分配和全局游戏设置。AI 绘本导入是内容草稿生成工具，不是无人审核的发布流程。

## 2. 故事与词汇

- 故事以唯一 `name` 识别，包含分组、展示标题、纯文本正文、分段双语 JSON、问题和词汇。
- 创建/更新故事时可同时 upsert 词汇和替换学员分配；多表写入应在事务中完成。
- 词汇按故事内小写单词唯一，包含中文释义、英文例句和例句翻译。
- CSV 导入必须校验表头、编码、必填字段、行数和错误行；部分成功时需明确报告。

## 3. 分组与访问

- `General` 是默认分组，不可删除或重命名。
- `ALL` 和 `__ALL__` 是筛选保留字，大小写不敏感，不能成为持久化分组名。
- 重命名分组会同步修改故事的 `group_name`；删除其他分组时故事移回 `General`。
- 当前“无分配记录”表示回退显示全部故事，不表示无权访问。若产品以后需要默认拒绝，必须同时迁移既有数据和测试。

## 4. AI 导入流程

1. 管理员先选择目标分组、Agent CLI、模型、题目数和可选提示词。
2. 上传 1–10 张按页面顺序排列的 JPEG/PNG/WebP 图片。
3. Backend 把请求转发到 FastAPI；FastAPI 调用所选 `agy`/`codex` CLI。
4. CLI 输出被解析成标题、主题、页面句子/翻译、词汇和阅读问题。
5. 浏览器展示可编辑草稿；管理员检查页序、正文、翻译、词汇和答案。
6. 管理员确认后再调用故事接口持久化。

CLI 或解析失败不得创建空故事或覆盖已有故事。

## 5. Agent CLI 约束

- 工具只允许配置中的 `agy` 或 `codex`；模型只允许相应工具列出的模型。
- 参数以数组方式传给进程，不使用 shell 拼接。
- 每次请求使用独立临时目录，限制执行时间和输出大小，并在结束时清理。
- CLI 登录资料是运行秘密，不进入返回值、日志或项目文档。
- 模型生成内容不可信：必须经过 Schema 校验、业务校验和管理员确认。

## 6. 全局设置

- 设置 API 只接受后端默认设置白名单中的键。
- 数值设置必须验证范围而不只是非负；怪兽池至少保留一个合法稳定标识。
- AI 提示词模板可编辑，但保存前必须限制长度；模板只能影响生成内容，不能改变 CLI 权限。
- 设置变更实时影响所有学员，应提供明确保存反馈和失败回滚。

## 7. 测试重点

- 故事 upsert 的事务、重复词、用户分配替换和 JSON 兼容。
- `General`/保留名称的新增、重命名和删除边界。
- CSV 引号、逗号、空行、Unicode、坏表头和大文件。
- AI 上传数量、类型、大小、页序、超时、非 JSON 输出和 CLI 不可用。
- 草稿确认前不写数据库；保存失败不丢失可编辑草稿。
