# 歌曲歌词学习

## 目标

让孩子使用自己喜欢的英文歌曲学习歌词中的句子和单词。第一版输入是一份完整 MP3，优先通过 LRCLIB 获取带时间戳的 LRC，也支持管理员上传自有 LRC；不切割 MP3 文件。

## 歌词来源与匹配

第一版不在本地部署 Whisper 等 AI 模型。家长上传 MP3 后，后端读取歌曲标题、歌手、专辑和音频时长，调用 LRCLIB 公共 API 的 `/api/get` 接口查找同步歌词（`syncedLyrics`）。接口只接收歌曲元数据，不上传 MP3；应用应设置自己的 User-Agent 并遵守 429 限流响应。

如果精确查询没有结果，使用 `/api/search` 返回候选歌曲，由管理员确认正确版本。匹配时优先比较音频时长（通常需要与 LRCLIB 记录相差约 2 秒以内），同时核对歌手、专辑和歌词内容。若只有普通歌词、时长不一致或版本不确定，不能静默保存，应提示管理员上传自有 LRC 或手动编辑。保存来源、LRCLIB ID 和匹配时长，便于追溯。

## 播放模型

LRC 每行提供一句歌词的开始时间。系统按下一句的开始时间推导当前句的结束时间，最后一句使用音频总时长。点击歌词时，播放器把 `currentTime` 设置为句子开始时间，并在句子结束时暂停；单句循环重复同一时间区间，整首播放忽略句子边界。

LRC 解析器需要支持 `[mm:ss.xx]`、`[mm:ss:xxx]`、同一句多个时间戳、空行和元数据标签。管理员可以试听并微调每句的开始、结束时间，以处理拖音、重复歌词和句后间奏。

校对界面将相邻歌词视为共享同一个时间边界：修改句子 A 的结束时间会同步修改句子 B 的开始时间；修改句子 B 的开始时间也会同步修改句子 A 的结束时间。首句开始时间和末句结束时间没有相邻项，只修改自身。

## 管理员流程

1. 上传或选择完整 MP3，自动读取歌曲元数据和时长。
2. 通过 LRCLIB API 查询同步歌词并展示候选版本。
3. 确认匹配版本；无结果或版本不符时粘贴/上传自有 LRC。
4. 自动解析歌词并按时间排序。
5. 逐句试听、修改时间和确认文本。
6. 为歌曲选择或确认目标单词（第一版最多 20 个），并保存单词练习配置。
7. 点击“AI 翻译歌词”，生成并缓存整句中文和目标单词释义；AI 暂时不可用时仍可使用英文逐句播放。

保存前必须校验时间非负、起止时间有效、句子顺序不倒序、音频格式可播放，且不得把 LRC 的元数据标签当作歌词内容。

## 学员流程

当前歌曲学习页仅对管理员开放，用于继续校对和优化功能；普通学员地图不展示入口。完成稳定性和内容审核后，再开放学员入口。

- 点击句子播放对应区间，当前句保持高亮。
- 支持单句循环、上一句、下一句和整首播放。
- 点击目标词可听发音、看释义和歌词上下文。
- 逐步练习目标词拼写，并为后续听音选词、歌词填空和图片选词保留扩展入口。
- 分别保存听懂、认词和拼写进度。

第一版不对孩子的唱歌录音做硬性评分，因为拖音、伴奏和连读会使普通语音识别产生误判。后续可单独设计跟唱评测。

## 验收标准

- 同一份 MP3 可以稳定播放整首、单句和单句循环，不生成重复音频文件。
- LRC 时间戳解析正确，重复时间戳和最后一句边界可处理。
- 管理员可以试听并修正边界，刷新后配置仍存在。
- 移动端自动播放受限时给出明确的点击播放提示。
- 页面退出或切换歌曲时暂停音频并清理事件监听器。
