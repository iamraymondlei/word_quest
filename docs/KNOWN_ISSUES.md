# 已知问题

本文件只记录截至 2026-08-26 仍能从当前代码或配置确认的问题。历史上已修复的事项位于 `archive/`，不在这里保留流水账。

## WI-001：空库初始化脚本的外键建表顺序错误

- **状态**：Open
- **证据**：`db/init.sql` 在创建 `islands` 前创建 `user_island_access`，但其外键引用 `islands(id)`。
- **影响**：在严格的空 MySQL Schema 上一次执行可能失败，不能满足可重复初始化要求。
- **临时规避**：人工复制脚本时先创建 `users`、`islands`，再创建关联表；不要直接对生产库执行。
- **目标修复**：提供版本化 migration，并在空库 CI 中验证。

## WI-002：Schema 有三份不一致的事实源

- **状态**：Open
- **证据**：`db/init.sql` 缺少 `translation_stats_json`、`story_groups` 和 `game_settings`；后端启动与 Jest `globalSetup` 各自补齐不同结构。
- **影响**：不同启动路径得到不同 Schema，部署和测试结果可能漂移。
- **临时规避**：部署前比较 `db/init.sql`、`initializeDatabaseSchema()` 和测试 Schema；以现有数据库实际结构为准并先备份。
- **目标修复**：迁移到单一、有序、版本化 migration，测试复用同一 migration。

## WI-003：迁移/测试数据库初始化失败不会使进程失败

- **状态**：Open
- **证据**：后端 `initializeDatabaseSchema()` 和 Jest `globalSetup` 捕获异常后只打印日志。
- **影响**：应用或测试可能在不完整 Schema 上继续运行，产生误报或运行期失败。
- **临时规避**：启动/测试后检查日志并执行健康与关键表检查。
- **目标修复**：非可选 migration 失败时快速失败并返回非零退出码。

## WI-004：缺少认证与服务端授权

- **状态**：Open / High
- **证据**：用户按用户名登录；`Admin` 名称可获得管理员标记；管理路由没有认证/授权中间件。
- **影响**：任何能访问接口的人都可能读取或修改用户、金币、故事、分组、设置和进度。
- **临时规避**：仅绑定可信本机或受防火墙保护的家庭 LAN，不暴露公网。
- **目标修复**：引入真实身份认证、会话和基于角色的服务端授权。

## WI-005：CORS、监听和局域网暴露过宽

- **状态**：Open / High
- **证据**：Express 使用默认 `cors()`；FastAPI 允许所有 origin/method/header；Compose 端口未限制为回环地址。
- **影响**：同网段或被转发的来源可跨站调用无认证 API。
- **临时规避**：主机防火墙限制来源，非必要端口绑定 `127.0.0.1`，不要配置公网转发。
- **目标修复**：显式来源白名单、回环绑定及受控反向代理。

## WI-006：配置中存在硬编码敏感/主机专属值

- **状态**：Open / High
- **证据**：`docker-compose.yml` 含数据库凭据值、个人宿主挂载路径和固定 WSL 代理地址；数据库配置/测试脚本也有凭据默认值。
- **影响**：秘密泄漏、环境不可移植，且可能误连错误数据库。
- **临时规避**：运行时用受保护的环境文件覆盖，限制 Git/文件权限并轮换已暴露凭据。
- **目标修复**：只保留变量引用和安全占位符，使用专用秘密管理及相对/可配置挂载。

## WI-007：内部错误信息返回客户端

- **状态**：Open
- **证据**：健康检查、多个控制器、通用错误中间件及 AI `/parse` 会返回 `err.message` 或异常字符串。
- **影响**：可能泄露数据库结构、主机路径、CLI 细节或敏感配置。
- **临时规避**：限制网络访问并审查日志/响应；不要向外部用户转发错误原文。
- **目标修复**：公开稳定错误码，原始异常仅进入脱敏日志。

## WI-008：前端没有自动化测试

- **状态**：Open
- **证据**：Frontend 只有 `dev`、`build`、`preview` 脚本，没有单元、组件或端到端测试配置。
- **影响**：四种复杂关卡、设备限制和管理流程主要依赖人工回归。
- **临时规避**：每次相关变更执行 [TESTING.md](TESTING.md) 的手工矩阵和生产构建。
- **目标修复**：增加组件测试及关键浏览器 E2E，覆盖电脑/iPad 分支。

## WI-009：本地开发端口默认值互相矛盾

- **状态**：Open / Low
- **证据**：后端代码缺省 8000，Vite `/api` 代理缺省目标为 8010，历史脚本/资料还出现其他端口。
- **影响**：按默认命令分别启动时，前端可能无法连接后端。
- **临时规避**：显式设置 `PORT` 和 `BACKEND_URL`。
- **目标修复**：统一 `.env.example`、脚本、Vite 配置和 Compose 端口说明。
