# Word Matching

## 1. 目的

Word Matching 是每个故事的第 3 关，内部模式值为 `translation`。它围绕故事句子提供朗读练习、语音识别、分词级匹配、发音问题定位、中文提示和粤语朗读。

## 2. 模式

### 阅读模式

- 按故事句子浏览英文和中文信息。
- 用户主动点击发音按钮播放英文 TTS；中文释义可使用粤语朗读。
- 提供句子结构或词义提示，减少直接暴露完整答案。

### 测试模式

- 请求浏览器麦克风权限并启动语音识别。
- 实时显示识别文本，但只在一轮朗读结束后给出最终诊断，避免识别过程中的瞬时红色误判。
- 使用规范化和分词对齐比较目标句与识别结果，展示正确部分及需要重读的词。
- 不自动跳到下一句，由学员确认后手动导航。

## 3. 浏览器与设备

- 目标设备包括电脑和 iPad Safari。
- Web Speech API 需要 HTTPS 安全上下文、麦克风权限及受支持浏览器。
- 不支持或拒绝权限时必须显示可恢复提示，并保留阅读模式。
- 语音识别候选、locale 和浏览器差异不得被当作确定的发音评分。

## 4. 文本匹配规则

- 比较时统一大小写并规范化空白。
- 标点符号不应破坏单词/字符槽对齐；展示仍保留原句标点。
- 长句导航必须使用当前句索引，切换句子时清理上一轮识别状态。
- 诊断应指出缺失、错读或额外词，不将短暂中间结果计入最终错误。
- 翻译统计按 `user_id + island_id` 保存至 `translation_stats_json`；结构变化需兼容旧记录。

## 5. TTS 规则

- 全局 TTS 语速由游戏界面统一控制，Word Matching 不维护重复的独立语速状态。
- 英文朗读与粤语释义使用明确的语言/voice 偏好，并允许浏览器无对应 voice 时降级。
- 进入新句、退出关卡或重新开始识别时停止仍在播放的语音。

## 6. 完成与测试重点

- 完成关卡后只设置关卡 3 的位图，不能覆盖其他关卡。
- 覆盖中英文标点、缩写、引号、换行、重复词、长句和识别额外词。
- 覆盖权限拒绝、浏览器不支持、识别无结果、中途取消和网络/系统中断。
- 在 iPad Safari 的真实 HTTPS 环境验证实时出字、停止诊断、手动下一句和 TTS。
